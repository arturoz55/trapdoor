# trapdoor

Sitio web de **trapdoor** — "decoding every funded Bitcoin wallet".

Traído desde la sesión *dec0ded.tech website remake* (su rama `claude/lucid-cannon-op6g3f` en `arturoz55/1` nunca se subió a GitHub, así que el sitio se recuperó de su artifact publicado: https://claude.ai/artifact/JXVPvpPWk6AUBnxLHGQNdZ).

Estado al traerlo:
- X enlazado a [@Trytrapdoor](https://x.com/Trytrapdoor)
- Botón *Connect Wallet* (MetaMask / Phantom / Coinbase Wallet)
- Precio BTC en vivo (CoinGecko) y saldos vía mempool.space

## Estructura
- `index.html` — página única y autocontenida (HTML + CSS + JS inline).

Para verla en local, basta con abrir `index.html` en el navegador o servirla con `python3 -m http.server`.
